Azure security assessment, in your browser

Checks a subscription against the Microsoft cloud security benchmark, CIS Microsoft Azure Foundations, the Well-Architected Framework, Azure landing zone policies and JSolve's own checks for Azure attack paths, basically a web version of the AzCmply PowerShell module. The results are also mapped to CIS Controls, DORA, ISO 27001, NIST CSF, NIST SP 800-53, PCI DSS, SOC 2 and CMMC. Read only. Assessment data goes from the Microsoft APIs to this page and nowhere else.

1Assess a subscription

Sign in with an account that has Reader on the subscription. For the Entra ID checks the account also needs a directory role that can read the directory, such as Global Reader.

The demo needs no sign-in: a synthetic subscription in which every resource is deliberately misconfigured.

2Collecting

Keep this tab open until the assessment is done. The collected data exists only in this tab: closing or reloading it ends the run. Working in other tabs is fine; on a phone or tablet, keep the browser in front.
